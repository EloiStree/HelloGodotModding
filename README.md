
# Hello Godot Modding

> I think it seems easy, but modding can be complicated. So let’s look for some documentation.

Godot has a superpower: its language is interpreted everywhere.
This means you don’t need a compiler like Lua,
or an interpreter installed on the machine like Python, since it’s built into the engine itself.

So it should be perfect for modding.
But is it really that easy?
Let’s find out.
